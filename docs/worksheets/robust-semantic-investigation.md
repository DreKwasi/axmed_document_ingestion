## Work log and evidence

- Added `EvidenceWorkspace` with stable JSON-node, atomic PDF/OCR-page, email-body, and fallback source-text references.
- Added the LangChain `search_evidence`, `inspect_evidence`, and `validate_candidate` tools. Inspection accepts several references in one call so table/layout, sibling JSON, or chronological email context can be considered together.
- Replaced one-issue repair feedback with stable, deduplicated structured issue sets, including new/resolved/persistent IDs and no-progress detection.
- Added application-owned limits for model/tool calls, inspected evidence volume, and elapsed investigation time. The model cannot alter these limits.
- Preserved LiteParse preparation. Each native page layout remains attached to its complete page evidence rather than being reconstructed or split from its table text.
- Replaced hand-written prose splitting with LangChain `RecursiveCharacterTextSplitter` for email and generic source text only. Native PDF/OCR pages deliberately remain atomic; page layout can exceed prose-sized chunks.
- Added direct JSON source-fact/canonical-value consistency checks and source-reference validation, including both sides of a supersession claim.
