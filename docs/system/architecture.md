## Current state

The project is a single-repository FastAPI + Vue 3 document-intelligence system. The source PRD is [axmed_document_intelligence_prd.md](../product/axmed_document_intelligence_prd.md); the execution order is in [implementation-plan.md](../plans/implementation-plan.md). The backend map is [backend/app/README.md](../../backend/app/README.md): `api/` composes HTTP, `application/` contains use cases, `domain/` contains canonical interpretation and LangChain extraction (`app.domain.langchain_extractor`), `infrastructure/` contains persistence, `workers/` contains Huey execution, `security/` contains redaction, and `core/` contains configuration. Checked-in Alembic migrations persist batches, documents, quotations, source files under a generated local name, fingerprinted mappings, review commands, correction evidence, review-learning jobs, email semantic-extraction jobs, processing events, model invocations, and evaluation runs in `data/app.db`; Huey state lives separately in `data/tasks.db`. Multi-file batch upload creates a `batches` record and derives aggregate progress directly from independent child document jobs; unparseable files fail safely with an isolated failure reason without disrupting sibling documents. The architecture follows a strict deterministic-first design: file validation, MIME parsing, native PDF table parsing, and SQLite schema memory check (0 LLM calls) execute first. Only ambiguous inputs (novel JSON schemas, email discourse price corrections, damaged OCR/free-form text) are scrubbed of PII and routed to LangChain powered by Google Gemini (`gemini-3.1-flash-lite`), which returns structured Pydantic outputs (`CanonicalQuotation`, `ProposedMappingSchema`). Output is then validated and normalized deterministically via `commercial_rules.py` before human review. A chained mapping provider allows seamless development and offline testing using recorded fixtures when `GEMINI_API_KEY` is not present. Processing events are the browser/worker boundary and are replayed through reconnectable SSE. GitHub Actions CI and automated PII audit checks enforce delivery hardening.
